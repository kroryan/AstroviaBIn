# Stellar template data

`spectral-library.fits` is a compact resampling of the 131 Pickles UVKLIB
standard-star spectra provided by the [STScI Reference Atlases](https://archive.stsci.edu/hlsp/reference-atlases).
Its wavelength grid is 3400–10500 Å in 5 Å steps. The FITS primary header
records the source and reference papers. It is generated by
`tools/scripts/build_spectral_library.py` from the original `pickles_uk_*.fits`
files; it is not pPXF code or a replacement for a calibrated observation.

For published work using these templates, cite Pickles (1998, PASP 110, 863),
the STScI Reference Atlases DOI 10.17909/t9-khb7-4049, and the relevant
AstroviaBin analysis libraries.
